# Multi-label Movie Genre Classification via Multi-source Text Fusion

> **Official Implementation** of the research: *"Multi-label movie genre classification using multi-source text fusion and transformer-enhanced multi-model ensemble"*

---

## 1. Description
This repository contains the official codebase and dataset pipeline for a **Transformer-enhanced ensemble learning framework** designed specifically for complex multi-label movie genre classification. 

Unlike traditional single-source approaches, this framework extracts and integrates multi-source textual metadata—**Titles, Summaries, and Plot Synopses**—to capture diverse semantic granularities. By fusing deep contextual embeddings generated by **RoBERTa** and **DeBERTa** encoders through a non-linear MLP ensemble network, the model effectively resolves the challenges of complex label co-occurrences and extreme long-tail class distributions in cinematic data.

---

## 2. Dataset Information
The research utilizes a curated multi-label dataset harvested from the **Internet Movie Database (IMDb)**.

* **Total Samples:** 4,430 unique movies.
* **Label Space:** 27 distinct genre categories (e.g., *Drama, Sci-Fi, Thriller, Crime*).
* **Data Fields:** Each sample includes synchronized fields for `Title`, `Summary`, and `Plot Synopsis`.
* **Complexity:** High density of label co-occurrence; each movie typically carries multiple tags (e.g., *Inception* is simultaneously tagged with Action, Adventure, Sci-Fi, and Thriller).
* **Source URL:** Available publicly on the [IMDb Official Website](https://www.imdb.com/).

## 3. Code Information
The project is structurally organized into four functional modules, reflecting a systematic end-to-end deep learning pipeline:

| Module/Folder | File Component | Key Responsibilities & Code Explanation |
| :--- | :--- | :--- |
| **`TorchDataset/`** | `dataset.py` | **Data Intelligence Layer**: Handles text cleaning, specialized tokenization for RoBERTa/DeBERTa, and Multi-label One-hot mapping. |
| **`Model/`** | `networks.py` | **Architectural Core**: Defines the dual-encoder setup, the Shared Transformer Fusion Module, and the final MLP Ensemble layers. |
| **`Train/`** | `main.py`, `trainer.py` | **Optimization Engine**: Manages training loops, configures Binary Cross-Entropy (BCE) losses, handles backpropagation, and saves checkpoints. |
| **`Evaluation/`** | `metrixCaler.py` | **Validation & Analytics**: Computes strict evaluation metrics (Subset Accuracy, Macro/Micro F1, Hamming Loss) and tracks validation loops. |

---

## 4. Methodology
The implementation follows a rigorous five-stage experimental execution:

1. **Data Preprocessing:** Cleaning, tokenizing, and padding multi-source text fields synchronously.
2. **Encoder Integration:** Extracting structural contextual embeddings using frozen/unfrozen RoBERTa and DeBERTa configurations.
3. **Transformer Fusion:** Modeling text interdependencies between Title, Synopsis, and Summary via cross-source **shared attention mechanisms**.
4. **Ensemble Meta-learning:** Feeding base-learner prediction probabilities into an optimized non-linear Multi-Layer Perceptron (MLP) to output final multi-label distributions.
5. **Multi-label Evaluation:** Conducting performance metrics verification, SOTA benchmarking, and per-class ROC-AUC visualization.
